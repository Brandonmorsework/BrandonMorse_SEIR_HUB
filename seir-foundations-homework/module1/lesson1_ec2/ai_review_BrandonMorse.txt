1. Why might SSHing into my ec2 instance be working properly, but putting http://<Public IP ADDRESS> not be displaying the webpage?

AI Response: Security group doesn’t allow port 80
This is the #1 culprit. SSH works because you opened port 22, but HTTP needs its own inbound rule: Type HTTP, Port 80, Source 0.0.0.0/0. If you’re using HTTPS, you’ll need port 443 as well.
Nothing is listening on port 80
The web server (nginx, Apache, your app) may not be installed, not running, or crashed.

Answer: I created inbound rules and selected the wrong security group, believing I was selecting the tailored security group with port 80 and port 22.
